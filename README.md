# SUPIT (Vue)

College project (Internet technology S3): 6 versions of the same web app, built to compare UX and DX. This branch is Vue 3 + Vite + Pinia + Vue Router + Headless UI + Tailwind, with lazy routing and async `Contact.vue`.

https://supit.k1k1.dev

```
npm i
npm run dev
npm run build
```

`vue-full` is the same stack without lazy routing. Master README has the comparison table and Lighthouse scores.
