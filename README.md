# SUPIT (React Full)

College project (Internet technology S3): 6 versions of the same web app, built to compare UX and DX. This branch is React 18 + Vite + Redux Toolkit + Headless UI + Tailwind, fully loaded (no lazy routing).

https://supit.k1k1.dev

```
npm i
npm run dev
npm run build
```

`react` is the lazy-routed variant. Master README has the comparison table and Lighthouse scores.
